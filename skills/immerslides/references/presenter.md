# 簡報者模式

在觀眾畫面按 `P`，或使用控制列的「簡報者模式」按鈕，開啟獨立視窗。再次開啟會聚焦既有的簡報者視窗。

簡報者視窗顯示目前畫面、下一個畫面、逐頁講稿與經過時間。兩個視窗使用同一份播放狀態，在任一邊前進或後退都會同步。程式碼與流程有分段時，下一個畫面優先預覽同頁的下一段。

## 撰寫講稿

在每筆 slide metadata 加入可選的 `notes` 字串。換行會保留在講稿區。

```tsx
slides: [
	{
		id: 'opening',
		title: '開始之前',
		steps: 1,
		notes: '先說明今天的目標。\n確認觀眾看得到投影畫面。',
	},
	{
		id: 'code',
		title: '逐段理解程式碼',
		steps: codeSteps.length,
		notes: '依序說明輸入、驗證與結果。\n每段留出提問時間。',
	},
],
```

講稿不顯示在觀眾畫面。沒有 `notes` 時，簡報者視窗會保留講稿區並顯示提示。這個欄位是純文字，不解析 HTML 或 Markdown。

## 計時與視窗

計時使用時間戳計算，從開啟簡報者模式開始。可暫停、繼續與重設。計時不會自動推進投影片。

將觀眾畫面放到投影螢幕，再在自己的螢幕保留簡報者視窗。關閉簡報者視窗不影響觀眾的播放進度，可再次開啟。

瀏覽器需要允許這次開啟彈出視窗。若開啟失敗，播放器會顯示提示。兩個視窗屬於同一次播放，不需要新增網站路由或另外維護進度。

## 驗證

- 開啟與重複開啟模式，確認只保留一個簡報者視窗。
- 從兩邊前進、後退，確認頁面與分段同步。
- 檢查目前講稿與下一個畫面，並確認講稿沒有出現在觀眾 DOM。
- 測試計時暫停、繼續、重設，以及關閉後重新開啟。
- 開啟減少動態效果，確認兩個預覽仍呈現正確狀態。
