# Features and when to use them

The features below are part of the public capabilities of immerslides. The starter's feature tour shows the most common ones. Choose them to fit the material. A formal deck does not need to include all of them.

| Feature                                      | When to use it                                        | Entry point and limits                                                                                                                                                                                                                                                                                                                                                  |
| -------------------------------------------- | ----------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Cover, content, and ending                   | Build a consistent presentation layout                | `layout` on `SlideFrame`. Fixed at 1600 × 900, scaled to fit the window.                                                                                                                                                                                                                                                                                                |
| Columns, labels, and notes                   | Compare two views or highlight a detail               | `immerslides-columns`, `immerslides-label`, `immerslides-note`.                                                                                                                                                                                                                                                                                                         |
| Complete flow diagrams                       | Explain an ordered process on one page                | `Timeline`, with one to three nodes per row. Supports the focus, good, warn, and bad states.                                                                                                                                                                                                                                                                            |
| Dark code window and highlighting            | Show a short program or protocol message              | `CodeBlock` takes the raw string, an optional file name, and a `language`. Supports common languages and aliases, keeps line breaks and indentation, and renders the text safely.                                                                                                                                                                                       |
| Line-by-line code focus                      | Explain an algorithm or configuration in sections     | `CodeBlock.steps` defines line ranges and descriptions, and `step` selects the current section. Keeps syntax colors, dims the other lines, and brings the focus into view.                                                                                                                                                                                              |
| Step-by-step flow focus                      | Explain data or an operational flow immersively       | `Timeline.steps` defines sections by node ID. The current node and its connectors are emphasized as `step` changes.                                                                                                                                                                                                                                                     |
| Free composition                             | Use different layouts for text, code, and flows       | `CodeWindow`, `HighlightedCode`, `StepDescription`, `FlowNode`, and `FlowConnector`. They share the implementation with the ready-made layouts.                                                                                                                                                                                                                         |
| Smooth chapter navigation                    | Keep your place in a long talk                        | Set `chapters` and `Overlay: ChapterGuide`. Chapters are derived from the same slide order.                                                                                                                                                                                                                                                                             |
| URLs, slugs, and history                     | Share one page or a specific step                     | Each slide can set a `slug`, which is otherwise generated from its title. Supports chapter aliases, `#/15` page jumps, reloads, and browser back and forward. Build links with `getSlideHref`.                                                                                                                                                                          |
| Whole pages and a few steps                  | Set the click rhythm to fit the talk                  | `steps: 1` by default. Extra steps are driven by `step` in your JSX, and content is not forced to reveal line by line.                                                                                                                                                                                                                                                  |
| Keyboard and control bar                     | Present live                                          | Arrow keys, Space, Page Up, and Page Down. You can type a slide number, or edit the current number below, then press Enter to jump or Esc to cancel. The control bar hides when idle and appears on pointer movement or keyboard focus.                                                                                                                                 |
| Chapter and thumbnail menu                   | Find a slide by outline or by look                    | Press O to open. The text outline is a collapsible tree of chapters and slides. The thumbnail view groups slides by chapter. Clicking a slide jumps to it and updates the URL.                                                                                                                                                                                          |
| Help and full screen                         | Present on stage                                      | Press ? for help and F to toggle full screen. Esc closes menus. Full screen depends on the browser and the host's permissions.                                                                                                                                                                                                                                          |
| Presenter view                               | Read your notes while the audience watches the slides | Press P to open a separate window. It shows the current and next views, the notes for each slide, a timer, and playback controls, all in sync with the audience view.                                                                                                                                                                                                   |
| Auto-save and start over                     | Continue the talk after a reload                      | sessionStorage for the same tab. Use `version` to handle content revisions, and `fresh` or `actions.restart()` to reset.                                                                                                                                                                                                                                                |
| Static previews                              | Show thumbnails and compare page designs              | `SlidePreview` does not start a playback provider. You can choose the slide and the step.                                                                                                                                                                                                                                                                               |
| Fade and custom transitions                  | Connect whole pages smoothly                          | `fadeTransition`, or a custom `TransitionDefinition`. Returns Web Animations API animations with a finite duration.                                                                                                                                                                                                                                                     |
| Transition snapshots and in-step transitions | Carry the same graphic across pages or steps          | A custom `capture` reads the state before a change, and `animateStep` handles changes within a step. `freezeEntranceOnNavigation` shows a page's specified state directly when navigating.                                                                                                                                                                              |
| Reduced motion                               | Respect the user's preference for less animation      | The player, ChapterGuide, and the built-in styles respect the system setting. Custom content uses `still`, `reducedMotion`, or `useReducedMotion()`.                                                                                                                                                                                                                    |
| Custom slide content                         | Native JSX, SVG, and interactive buttons              | `RenderSlide` receives `SlideRenderProps`. Animations and actions must not affect static previews.                                                                                                                                                                                                                                                                      |
| Extra controls and help                      | Course-specific actions or teaching aids              | `Controls` receives the playback state and actions. `Help` adds content to the help menu.                                                                                                                                                                                                                                                                               |
| Marks for example highlights                 | Remember slides to revisit later                      | In the starter's toolbar, ☆ marks the current slide. The count next to it opens the shared menu with the "Marked" filter applied. Text and thumbnails keep the original slide numbers, and empty chapters are hidden. Each slide has a star in its top-right corner to mark or unmark it, and clicking the slide views it. Reloading or starting over clears the marks. |
| Playback-only state                          | Timers or activity that spans slides                  | `Provider` receives `children` and `fresh`. Use `usePlayback()` inside it. Previews do not mount it.                                                                                                                                                                                                                                                                    |
| Custom slide overlays                        | Persistent guidance across slides                     | `Overlay` receives the playback state, the viewport, and the scale. `reserveWidth` reserves width for the overlay.                                                                                                                                                                                                                                                      |
| Return links and handouts                    | Integrate with existing material or a site            | `Player.homeHref` shows a link back. `handout` shows a link to course material in the help menu.                                                                                                                                                                                                                                                                        |
| New projects and project skills              | Reuse the same technology and style                   | `immerslides create <directory>` copies the starter and the skill. Install and build with pnpm.                                                                                                                                                                                                                                                                         |

## Custom playback features

`usePlayback()` can be used inside `Provider`, `Controls`, `Overlay`, and the renderers during real playback. Static previews do not provide that context. Shared renderers should prefer the props they receive.

`Overlay` is a single component slot. To show several overlays, combine them in one custom component. `ChapterGuide` can be one part of that. A custom overlay decides its own position and whether it reserves width.

Custom animations should end at the final state of the JSX and CSS. The player cancels the animations when a transition finishes or is interrupted. Do not depend on fill effects that persist.

## Output

`pnpm build` in the package repository produces a publishable library. The same command in a generated presentation project builds a static Vite site. Each one is determined by its own `package.json`.

The package has no built-in Markdown import, PDF or PPTX export, WYSIWYG editor, or online agent panel. If you need those, evaluate a dedicated tool.
